# 前端交互说明

## 视觉与信息组织

深森林绿导航、暖白工作区、鼠尾草色强调、细边框和轻阴影统一视觉层级。采用真实目录统计与任务引导，不虚构趋势数据。主内容保持稳定位置，列表、表单、来源展示和确认框使用同一套反馈方式。

导航按工作空间、组织与成员、权限与资源、个人空间分组。管理员看到全部管理入口；普通用户只看到“我的权限”和“账号安全”，不加载管理员目录。管理员身份不能替代业务授权。

## 任务流程

| 任务 | 操作路径 | 关键反馈 |
|---|---|---|
| 建立基础目录 | 部门→用户→应用→角色→菜单按钮→API | 新增/编辑弹窗；不可变编码/归属不混入编辑；独立启停 |
| 建立继承 | 选择高级角色→选择被继承角色→确认方向→预览 | 高级角色获得权限，环路拒绝，直接边与最终权限分开 |
| 分配业务访问 | 用户→角色、角色→权限、权限→API | 三个标签页对应三组关系，右侧查看直接关系，下方查看最终来源 |
| 本人验证 | 我的权限→刷新→发送验证请求 | 直接/继承来源、导航容器、API 200/403 清晰区分；个人来源显示起终角色与继承级数，管理员预览显示完整角色名称链 |
| 回收访问 | 撤回关系/解除继承/停用→确认 | 提示影响，保留其他有效来源；下一次鉴权读取最新配置 |
| 账号安全 | 原密码→新密码→再次输入→确认 | 两次输入一致；成功清除身份并重新登录 |

## 列表和表单

用户后端每页 10 条，搜索与筛选**只针对当前页**，页面明确写“本页”；授权用户选择器以 25 条分批切换。其他目录当前全量读取。不能把本页搜索描述为全站搜索，也未做大规模目录压测。

每个页面有新增入口、空状态和刷新；状态用文本与标记共同表达。危险删除、停用、撤回和继承操作先确认，取消不写入；编辑表单只提交允许字段。业务校验由后端执行，错误保留供用户阅读。

## 状态与会话

请求有超时和错误提示；提交忙碌时防重复，切换来源对象时忽略过时响应，退出时清理身份与目录。Token 仅保存在当前标签页 sessionStorage，刷新可恢复，退出后不恢复。过期或凭证失效返回登录；403 显示业务错误。

页面地址保留 hash，前进/后退恢复页面而不新增历史条目。输入拥有标签，弹窗使用原生 dialog，危险操作支持 Escape 取消；有跳至主内容入口、减少动态效果和窄屏折叠导航。390px 验证页面整体无横向溢出，长表格在容器内部滚动。

## 组件边界

App 为页面壳与导航；console.ts 为 HTTP/身份/目录和通用操作；ResourceTable、EditorDialog、ConfirmDialog 复用管理行为；OverviewPanel、HierarchyPanel、GrantsPanel、MyPermissions 表达具体任务；OriginsList 统一来源展示，Icon 统一图标。

[真实页面截图](../design/README.md)来自隔离 H2 合成数据。浏览器验收包含创建编辑、取消、启停、继承、防环、授权绑定、个人访问、撤权、移动导航与连续前进后退，测试未使用模拟 API。

## 公司三表增量

管理员新增“数据导入”入口，三份文件→预览规则与数量→确认写入→查看员工；更换文件清除旧摘要。导入请求最长等待180秒，提交忙碌时防重，失败保留错误。用户列表可展开分公司、原部门、岗位和电话，支持单独设置密码；设置密码不自动启用。部门显示经理原始名称，功能节点可展开来源说明与五类原始授权矩阵。页头模式取自真实 system-info 接口。ImportPanel 只处理导入任务，复用 console.ts HTTP 边界。
